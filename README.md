## 核心项目
### AI 新闻情报平台
一个面向信息获取与业务研究场景的 AI 辅助情报工作流，用于完成多信息源采集、筛选、去重、分析与结构化输出。
**核心功能**
- 多信息源自动采集
- 信息筛选与去重
- AI 辅助内容分析
- 日报与结构化情报输出
- Web Dashboard
- 工作流评估与持续迭代
**当前真实运行数据**
- 配置 10 个信息源
- 5 天正式运行累计输出 49 条有效内容
- 单次审计约 54 条原始信息 → 12 条保留内容
- 按当前运行规模估算，每月处理约 1,620 条原始信息
- 每月形成约 294 条结构化有效信息
### AI 热点发现平台
一个用于内容运营与增长场景的热点发现工作流，通过平台热点榜自动获取趋势信息，并形成结构化热点池。
**核心功能**
- 多平台热点发现
- 抖音 / 蝉妈妈热点采集
- 自动 Top-N 排序
- 独立失败隔离的数据采集架构
- 热点池结构化管理
- 人工控制的素材与选题匹配
**产品决策**
在测试过程中曾尝试自动化素材匹配，但实际效果与复杂度不成比例，因此最终选择：
**热点发现 = 自动化**
**素材匹配 = 人工控制**
我更关注的是：
> 什么应该自动化，什么应该交给 AI，什么仍然需要人的业务判断。
> 完整项目案例即将补充。
## 我的 AI 工作方式
我会先拆解工作流，再判断不同任务应该由谁完成。
通常会区分：
- **自动化**：适合规则明确、重复执行的任务
- **AI**：适合内容理解、分析、分类、生成等任务
- **规则系统**：适合稳定、可验证的基础逻辑
- **人工判断**：适合高不确定性、需要业务经验的环节
最终目标不是“使用更多 AI”，而是让整个工作流：
**更高效、更稳定、更可评估，并能够真正产生业务价值。**
